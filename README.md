# 8-Bit SAP-1 Microprocessor with Python Assembler & Auto-Loader

A fully operational custom **8-bit SAP-1 (Simple-As-Possible) microprocessor** designed and simulated in **Logisim-evolution**. The project includes a complete hardware implementation along with a custom software toolchain consisting of a Python-based assembler and an automated RAM loading mechanism.

This work was developed as part of the **ETE 404: VLSI Technology Sessional** course at the **Chittagong University of Engineering & Technology (CUET)**.

![SAP-1 Final Top Level](screenshots/sap1_final_top.png)

---

## Overview

The SAP-1 architecture is a classic educational microprocessor design that demonstrates the fundamental principles of computer organization. This implementation extends the original concept with several enhancements, including dedicated bit manipulation units, an expanded instruction set, and a fully automated memory loading system.

The design maintains the educational clarity of the classic SAP-1 while adding practical features that make it suitable for more complex programming exercises.

---

## Key Features

- **8-bit Data Path** with a 4-bit address bus supporting 16 memory locations
- **Complete Register Set**: Accumulator (A), B Register, Instruction Register (IR), Program Counter (PC), and Memory Address Register (MAR)
- **16-Instruction ISA** covering arithmetic, logical, data movement, branching, and bit manipulation operations
- **Dedicated Barrel Shifter** supporting variable logical shifts (0-7 bit positions)
- **Ring Rotator** for cyclic rotations
- **Flag Logic**: Synchronous Carry flag and combinational Zero detection
- **Custom Python Assembler** with support for labels, `.ORG` directives, and `DB` data definitions
- **Hardware Auto-Loader** that transfers machine code from a template ROM into working SRAM

## Instruction Set Architecture

The processor implements a 16-instruction set. Instructions are encoded in a single byte where the upper nibble represents the opcode and the lower nibble typically contains an address or immediate value.

| Mnemonic | Opcode | Description                          | Addressing Mode |
|----------|--------|--------------------------------------|-----------------|
| LDA      | 0x0    | Load Accumulator from memory         | Direct          |
| LDB      | 0x1    | Load B Register from memory          | Direct          |
| STA      | 0x2    | Store Accumulator to memory          | Direct          |
| ADD      | 0x3    | Add B to Accumulator                 | Register        |
| SUB      | 0x4    | Subtract B from Accumulator          | Register        |
| AND      | 0x5    | Logical AND of A and B               | Register        |
| OR       | 0x6    | Logical OR of A and B                | Register        |
| XOR      | 0x7    | Logical XOR of A and B               | Register        |
| CLR      | 0x8    | Clear Accumulator                    | Implied         |
| SHIFT    | 0x9    | Logical shift using Barrel Shifter   | Immediate       |
| ROTATE   | 0xA    | Cyclic rotate using Ring Rotator     | Immediate       |
| JMP      | 0xB    | Unconditional jump                   | Direct          |
| JC       | 0xC    | Jump if Carry is set                 | Direct          |
| JNZ      | 0xD    | Jump if result is not zero           | Direct          |
| NOP      | 0xE    | No operation                         | Implied         |
| HLT      | 0xF    | Halt the processor                   | Implied         |

## Software Toolchain

### Python Assembler (`assembler_8bit.py`)

The assembler converts human-readable assembly source into a Logisim-compatible hex memory image. Supported features include:

- Symbolic labels
- `.ORG` directive for origin setting
- `DB` (Define Byte) for data initialization
- Automatic generation of both a hex image and a detailed listing file

**Usage example:**

```bash
cd Assembler
python assembler_8bit.py program.asm
```

This produces:
- `ram_image.hex` - Logisim v3.0 hex format memory image
- `listing.txt` - Address-by-address assembly listing

### RAM Auto-Loader

The hardware includes a debug-protocol based auto-loader. When activated, it sequentially copies the contents of a pre-loaded template ROM into the working SRAM, eliminating the need for manual memory initialization during simulation.

## Getting Started

1. **Open the Circuit**
   Launch Logisim-evolution and open `SAP1_8bit_Final.circ`.

2. **Assemble a Program**
   ```bash
   cd Assembler
   python assembler_8bit.py program.asm
   ```

3. **Load Memory**
   - Either load `ram_image.hex` manually into the RAM component, or
   - Use the built-in Auto-Loader to transfer the program from the template ROM.

4. **Simulate**
   Reset the circuit and run the simulation. Observe register values, bus activity, and control signals.

## Design Notes

- The control unit is implemented as a hardwired multi-phase sequencer driven by a ring counter.
- All registers are edge-triggered and synchronized to a common clock.
- The Zero flag is generated combinationally using an 8-input NOR gate.
- The Carry flag is stored in a dedicated flip-flop and updated by the ALU.
- Bit manipulation operations (SHIFT and ROTATE) are performed by dedicated hardware units rather than the main ALU, improving both clarity and performance in simulation.
